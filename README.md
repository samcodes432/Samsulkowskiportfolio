# Northline Studio Portfolio

A responsive, static web design portfolio ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a public GitHub repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your GitHub username).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root. Do not upload the containing folder instead.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**. Save.
4. After deployment, open `https://YOURUSERNAME.github.io`.

## Before sharing with potential clients
- Change the placeholder brand name **Northline Studio** if desired.
- Replace `hello@example.com` in `index.html` with an email you control. Update the mailto link and remove the demo warning.
- Replace the concept project previews with actual demo projects and links as you build them. These are currently *visual concepts only*, not functioning client sites.
- Review pricing and wording so they accurately describe the services you can deliver.
- If you're under 18, review client contracts and payment arrangements with a parent or guardian.

## Files
- `index.html` — page content
- `styles.css` — all design and responsive styling
- `script.js` — mobile menu and dynamic copyright year

No build step or paid dependencies required. Google Fonts requires an internet connection; system fallback fonts are provided.
